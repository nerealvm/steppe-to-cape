# Steppe to Cape

A bilingual design preview for a freight forwarding project between the CIS and Africa. Start with `index.html` (Русский) or `en.html` (English). No build step, API, external scripts or database. Serve this folder over HTTP, or deploy the root of `main` to GitHub Pages.

## What this edition does

- Shows an illustrative ocean leg between St Petersburg and Durban, not an advertised sailing or live vessel position.
- Lets a visitor reverse the direction and use the endpoints to build a freight brief. Copying and downloading happen in the browser. The site does not transmit enquiries, book freight or process payments.
- Identifies the project founders; in this public edition their portrait links lead to the original professional profiles. No third-party portrait files are distributed here.
- Respects reduced-motion preferences. Menu links, service descriptions and the map remain readable without scripting.
